## 🎨 THE SYSTEM

### Complete Workflow
```
Employee
   ↓
Submits Request
   ↓
Procurement Manager Reviews
   ↓
Store Officer Verifies & Issues
   ↓
System Tracks Costs & Updates Budget
   ↓
Analytics & Reports Available
```

### Key Features
✅ Multi-stage approval process  
✅ Real-time cost tracking  
✅ Budget management  
✅ Comprehensive reporting  
✅ Role-based security  
✅ Status tracking with timeline  
✅ Batch/serial number tracking  
✅ Automatic inventory deduction  

### Technology Stack
- React 18.3.1
- React Router v7
- Material-Tailwind
- Tailwind CSS
- Recharts
- Axios
- Spring Boot (backend)
- MySQL (database)
- JWT authentication
